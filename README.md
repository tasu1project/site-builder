# サイトビルダー（Site Builder）

ブラウザだけで動く、ジャンル選択式のランディングページ作成ツールです。
「どんなサイトを作りますか？」から種類を選び、内容を入力するとライブプレビューが更新され、
完成したページを 1ファイルのHTML（`index.html`）として書き出せます。サーバーは不要です。

## 収録テンプレート
- 講師 / コンサル
- キャンプ場 / 宿泊

## ファイル構成（このフォルダの中身すべてが必要です）
```
index.html              … ツール本体（エントリー）
builder.css             … ツールUIのスタイル
util.js                 … 共通ユーティリティ
lp-styles.js            … 「講師」テンプレートの出力用CSS
camp-styles.js          … 「キャンプ場」テンプレートの出力用CSS
template-instructor.js  … 「講師」テンプレート定義
template-camp.js        … 「キャンプ場」テンプレート定義
app.jsx                 … アプリ本体（React）
```

## GitHub Pages での公開手順
1. GitHub で新しいリポジトリを作成します。
2. このフォルダの **中身（index.html など8ファイル）をそのまま** アップロードします。
   （フォルダ階層を変えないでください。ファイルは同じ階層に置きます）
3. リポジトリの **Settings → Pages** を開きます。
4. **Branch** を `main`、フォルダを `/ (root)` に設定して **Save**。
5. 数分後、`https://ユーザー名.github.io/リポジトリ名/` で公開されます。
   URL を知っている人は誰でもブラウザでツールを利用できます。

## 利用について
- 入力内容はブラウザに自動保存され、次回も続きから編集できます（端末・ブラウザごと）。
- 「HTMLをダウンロード」で書き出した `index.html` が、配布・公開できる完成品です。
  CSSを内蔵した単一ファイルですが、フォント表示にはインターネット接続が必要です。
- 写真を多数登録すると自動保存の容量上限を超える場合があります。その場合も、
  ダウンロードしたHTMLには写真が埋め込まれます。

## 補足
- このツール自体はインターネット接続時に動作します（React等を読み込むため）。
- 入力データはどこにも送信されず、すべて利用者のブラウザ内で処理されます。
